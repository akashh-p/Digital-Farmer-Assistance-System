\section{Testing Approach}
A comprehensive, multi-tiered testing strategy guarantees the absolute reliability and operational accuracy of the system architecture under varying load parameters. The testing protocol leverages three definitive evaluation paradigms:
\begin{enumerate}
    \item \textbf{Unit Testing Framework:} Granular validation methodologies are deployed to scrutinize the behavioral accuracy of highly isolated functions—particularly cryptographic password hashing mechanisms and JSON web token string generation—independently from the broader application state.
    \item \textbf{Integration Interfaces:} Rigorous evaluations analyze the operational handshakes between disparate architectural components. Crucially, integration testing ensures that API route handlers perform uninterrupted, synchronous data exchanges accurately bridging the Node.js application server, the local MySQL database persistence layer, and the external third-party OpenWeatherMap APIs.
    \item \textbf{System and Usability Testing:} Extensive End-to-End (E2E) validations simulate a comprehensive farmer usage trajectory. Testing is heavily focused utilizing Chrome DevTools Device Mode to physically emulate low-resolution, mobile-viewport rendering, rigorously validating frontend HTML/CSS resilience and the accuracy of the multilingual interface.
\end{enumerate}
