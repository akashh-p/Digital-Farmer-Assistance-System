# Required Images for LaTeX Report

The following images should be placed in this folder (`docs/images/`) so they can be included in the LaTeX report. The names listed below correspond to the expected filenames (e.g., `screenshot_home.png` or `screenshot_home.jpg`).

1. **`screenshot_home`**
   - **Description:** System Home Page: Landing screen showing standard market prices, daily weather summary, and unified navigation menu components.

2. **`screenshot_login_farmer`**
   - **Description:** Farmer Login Interface: Mobile-first phone number and password authentication form.

3. **`screenshot_login_admin`**
   - **Description:** Admin Login Interface: Email and password form mapped exclusively for administrator user access tracking.

4. **`screenshot_dashboard`**
   - **Description:** Farmer Dashboard: Unified data stream rendering specific crop advisories, an integrated 5-day weather forecast, and local market price summary cards.

5. **`screenshot_market`**
   - **Description:** Market Prices Module: Searchable and highly filterable data table rendering recent crop prices tagged with the active date and source market coordinates.

6. **`screenshot_weather`**
   - **Description:** Weather Module: Rendered 5-day localized weather sequence showcasing the automated alert banners dynamically triggered by external extreme weather metric flags.

7. **`screenshot_advisory`**
   - **Description:** Crop Advisory Module: Rendered layout featuring season-filtered advisory content dynamically leveraging the application's native multilingual database translation labels.

8. **`screenshot_query`**
   - **Description:** Query Submission Form: Interactive module utilized by farmers to directly submit agricultural issue reports explicitly requesting expert administrative resolutions.

9. **`screenshot_admin_db`**
   - **Description:** Admin Panel Architecture: Backend CRUD (Create, Read, Update, Delete) portal exclusively used by administrative profiles to constantly manage advisory flows and market price points.

10. **`screenshot_schema`**
    - **Description:** Database Schema Verification Output: Visual snapshot confirming proper MySQL relational deployment, outlining foreign key constraint interactions across all six primary tables.

11. **`usecase`**
    - **Description:** System Use Case Diagram

12. **`classdiagram`**
    - **Description:** System Class Diagram
